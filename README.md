# Cuthbert — Open Problems

**Need → Cuthbert → missing piece → useful human → verified result.**

This repository powers the public Cuthbert site at `https://devinkc.github.io`.

The site shows real public bottlenecks, accepts structured bottleneck and resource submissions through GitHub Issue Forms, and tracks OPEN / MATCHED / SOLVED without inventing progress.

GitHub Issues are public. Do not submit private medical, financial, identifying, security-sensitive, or confidential information.
